# Emoji Keys

Animated emoji reactions tied to A-Z key presses while typing on webpages.

## Modes
- Off.
- Animate only: normal letter remains, matching emoji floats upward.
- Replace + animate: letter is replaced by emoji and animation also plays.
- Replace only: letter is replaced by emoji without animation.

The popup also controls emoji size and animation duration. Ctrl/Cmd/Alt shortcuts are ignored so normal browser shortcuts are not hijacked.
