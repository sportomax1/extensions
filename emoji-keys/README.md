# Emoji Keys 2.0

Turns ordinary A–Z typing into optional emoji replacement and/or visual typing effects.

## Modes
- Off
- Animate only (normal letters still type)
- Replace letters only
- Replace + animate

## Effects
Float, Burst, Confetti, Trail, Emoji Rain, and Sparkle.

## Other controls
- Four small Web Audio sound styles.
- Emoji size, effect duration, and intensity.
- Streak boosts for rapid typing.
- Fully editable A–Z emoji mapping.
- Optional locally stored A–Z typing heatmap.

Effects only respond to normal printable keypresses inside editable webpage fields; Ctrl/Command/Alt shortcuts are left alone.
