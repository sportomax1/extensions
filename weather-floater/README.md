# Weather Floater

A draggable weather overlay for normal webpages.

## Features
- Search city, ZIP, or place name.
- Use current location.
- Current temperature, feels-like, humidity, wind, and precipitation probability.
- Seven-day high/low forecast.
- Fahrenheit/Celsius toggle.
- Remembers last location, units, visibility, and screen position.
- Toolbar icon toggles the widget.
- Uses Open-Meteo; no API key required.

## Install
Load the `weather-floater` folder as an unpacked extension from `chrome://extensions`.

Chrome does not allow content-script overlays on protected pages such as `chrome://...` or the Chrome Web Store.
